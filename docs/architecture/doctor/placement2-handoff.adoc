== DEBT (accepted, not hidden) — `ReferralReplies` cycle → 5 value-type tests stay HOST

Commit-2 execution hit a *Maven reactor cycle* that the relocation plan did not foresee, and the
honest fix leaves a documented debt. Surfacing it loudly here per the no-masking rule.

*The cycle.* `ReferralReplies` builds a port type (`ReferralReply`), so `doctor-testkit` depends on
`doctor-port` (compile). But `ReferralReplies` is also used by 5 of doctor-port's OWN relocated tests
→ `doctor-port` would depend on `doctor-testkit` (test). Maven rejects `doctor-port ↔ doctor-testkit`
regardless of scope (module-level, scope-blind). Measured users of `ReferralReplies`: 5 PORT + 1 CORE
+ 4 HOST.

*Root cause (not the cycle itself).* Our test modules run in the *bare-JVM JCL* (flat surefire
classpath) yet cover code that lives in *bundles* (classloader-isolated at runtime). On a flat
classpath a shared fixture must be a separate module, and a module cannot depend back on what tests
it. In the OSGi world this is not a cycle at all: a test *fragment* IS its host (shared classloader),
so `ReferralReplies` would be visible with no reverse edge. A fragment cannot fix it *now* though — the
cycle is at Maven build time; a fragment acts at framework runtime, too late.

*The decision (option B, signed off).* `ReferralReplies` lives alone in `doctor-testkit` (which
depends on `doctor-port` — no return edge, no cycle), consumed `scope=test` by doctor-core and
seed-outcluster. The *5 value-type tests that use it stay in seed-outcluster (HOST)* instead of descending to
`doctor-port/src/test`: `MedicalRecordTest`, `ConsultationReportSerializationTest`,
`ConsultationReportExpectationTest`, `DoctorRecordsTest`, `MedicalRecordEfficacyConfoundedTest`. The
~19 value-type tests with no `ReferralReplies` dependency DO descend to `doctor-port/src/test`.

*The debt.* Those 5 tests cover port-level value types but physically sit in seed-outcluster — not where
their subject lives. Zero duplication, zero masking; it is a placement compromise forced by the
bare-JVM test model. *It resolves for free when the test-fragment chantier lands* (memory
`osgi-testkit-framework-injection-idea`): as fragments sharing the bundle classloader, the fixture is
visible with no module/cycle, and the 5 tests move home. Until then this is the one acknowledged
asymmetry in the otherwise-clean relocation.
